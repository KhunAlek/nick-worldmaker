Your character appears on the Baseplate. Nothing else changes yet.
In Output

Start here

One small result: make the server say it is ready

Important: open one step at a time. Do not create anything that the current step does not ask for.
Step 1 — Make the Studio windows visible
  1. At the top of Roblox Studio, click Window.
  2. Click Explorer.
  3. Open Window again and click Properties.
  4. Open Window again and click Output.

Explorer is the list of objects in the game. Output is where code messages and errors appear.

Step 2 — Create the World folder
  1. In Explorer, find Workspace.
  2. Move the mouse over Workspace. Click the small + that appears.
  3. Choose Folder.
  4. A new Folder appears underneath Workspace. Rename it exactly World.
Stop and check:
Workspace
└── World
If World is not directly under Workspace, drag it onto Workspace before continuing.
Step 3 — Add the empty folders

Repeat the same + → Folder → rename action.

  1. Under World, add: Ground, NPCs, NPCHomes, Resources, and Buildings.
  2. Under ReplicatedStorage, add: Remotes and GameState.
  3. Under ServerStorage, add: Templates.
Stop and compare: expand the folders in Explorer and compare them with the full picture lower on this page. Do not type this structure anywhere.
Step 4 — Create exactly one Script
  1. In Explorer, find ServerScriptService.
  2. Move the mouse over it and click +.
  3. Choose Script. Do not choose LocalScript or ModuleScript.
  4. Rename the new Script exactly WorldServer.
  5. Double-click WorldServer.
  6. Delete the starter line print("Hello world!").
Correct
ServerScriptService
└── WorldServer
Wrong
Workspace
└── Script
Step 5 — Type the first Luau line

print tells Roblox to place a message in Output. Build the line in three pieces:

  1. Type print.
  2. Add parentheses: print().
  3. Put the exact message inside quotation marks.
VERSION 1 SERVER READY
Check the completed line after typing yoursprint("VERSION 1 SERVER READY")
Before Play: predict what will appear in Output. Nothing new should appear on the Baseplate yet.
Step 6 — Script audit before Play

This check prevents the exact problem that creates repeated Hello world! messages.

  1. Use the Explorer search box and search for Script.
  2. Open every Script shown by the search.
  3. Keep the one named WorldServer under ServerScriptService.
  4. Delete accidental Scripts directly under Workspace.
  5. Delete unnecessary Scripts that still contain print("Hello world!").
  6. Clear the Explorer search box.
Step 7 — Play, read Output, and test again
  1. Clear old Output messages.
  2. Press Play.
  3. Find VERSION 1 SERVER READY in Output.
  4. Press Stop.
  5. Clear Output and press Play a second time.
  6. The readiness message should appear once again.
About unrelated errors: an error containing a name such as cloud_...MA2Theme comes from a plugin or external package. It is not proof that WorldServer failed. The page will identify this after you paste Output.

I see Hello world!

That Script is in the wrong place. Stop Play, delete the accidental Script under Workspace, and keep WorldServer under ServerScriptService.

            
I see “Incomplete statement”
One line is unfinished. Open the Script named in the error, check its line number, and repair the missing quote, parenthesis, or incomplete text.

            
I see cloud_... or MA2Theme
This is usually plugin code. First check whether VERSION 1 SERVER READY appears. The website will treat the plugin error separately instead of blaming your Script.
