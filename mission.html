Part 1 · Know your tools

Where code lives and where results appear

Explorer shows every object in the game as a tree. It answers: “Where is my Script?” and “Did I use the exact name?”

Properties shows settings for the selected object.

Output is the game’s report window. It shows messages from code, warnings, and runtime errors.

Script Editor is where you write Luau. It opens when you double-click a Script.

  1. Open Explorer and Properties from the Window menu or Home toolbar.
  2. Open Output from the Window menu or Script toolbar.
  3. Keep the 3D Baseplate visible.
Checkpoint A: do not continue until Explorer, Properties, Output, and the Baseplate are all visible.
Part 2 · Organise the project

Build the folder skeleton

A Folder is an organisational container. It does not create anything visible and it does not run code. It gives future objects a predictable home.

  1. Inside Workspace, create a Folder named World.
  2. Inside World, create Ground, NPCs, NPCHomes, Resources, and Buildings.
  3. Inside ReplicatedStorage, create Remotes and GameState.
  4. Inside ServerStorage, create Templates.

These names describe where later parts of the game will live: the island, settlers, their return points, resources, buildings, shared values, messages, and hut template.

Checkpoint B: compare every name and location with the required hierarchy below. Capital letters matter.
Part 3 · Create server code

Make the WorldServer Script

A Roblox game has a server and one or more clients. The server controls shared rules and world state. A client is one player’s controls, camera, and interface.

Later, the real resource totals and hut will belong to the server so every player sees the same truth.

  1. In Explorer, find ServerScriptService.
  2. Click + and choose Script — not LocalScript or ModuleScript.
  3. Rename it exactly WorldServer.
  4. Double-click it and delete Studio’s starter line.
Checkpoint C: Explorer must show ServerScriptService > WorldServer, and WorldServer must be a normal Script.
Part 4 · Write real Luau

Construct the line yourself

print is a Luau function. A function is a named instruction that performs a job. The job of print is to send information to Output.

Step 1 — Type the function name

print

Nothing runs yet. Luau still needs to know what information you are giving to the function.

Step 2 — Add parentheses

print()

Parentheses hold the information passed into a function. The information inside is called an argument.

Step 3 — Add a string

The exact message is:

VERSION 1 SERVER READY

Text in Luau is called a string. A string must be surrounded by quotation marks. Put the message inside the parentheses and add the quotation marks yourself.

Predict before running: what exact line should appear in Output? What should change in the 3D world?
Check the completed line only after writing yoursprint("VERSION 1 SERVER READY")
Part 5 · Run and observe

Prove what the code does

  1. Clear old messages from Output.
  2. Press Play.
  3. Confirm your character appears on the Baseplate.
  4. Confirm Output shows VERSION 1 SERVER READY exactly once.
  5. Check that your Script produced no unresolved red error.
  6. Press Stop.

Nothing new appears in the world because print() reports information. It does not create parts or move characters.

Small experiment: temporarily change only the text inside the quotation marks. Run once and observe what changes. Then restore the required message.
Part 6 · Debug on purpose

See what an error looks like

  1. Temporarily remove the final quotation mark.
  2. Notice how the Script Editor marks unfinished code.
  3. Inspect the error information.
  4. Restore the quotation mark.
  5. Run again and prove the error is gone.

This experiment is not submitted. It teaches you where to look when code appears to do nothing.
